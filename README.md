Car Racing Game

1. Project Overview

Car Racing Game is a simple, text-based game developed using Python. The player controls a car on a three-lane road and tries to avoid an enemy vehicle that appears randomly in one of the lanes.

The player can move left or right, use shortcut commands to switch lanes, or quit the game.

The game ends when the player's car collides with an enemy or when the player attempts to cross a road boundary.

---

2. Features

- Three-lane road system.
- Random enemy position generation.
- Left and right car movement.
- Shortcut movement using "AA" and "DD".
- Collision detection.
- Left and right boundary detection.
- Score tracking.
- Quit option.

---

3. Controls

Key| Action
"A"| Move left
"D"| Move right
"AA"| Move from lane 3 to lane 1
"DD"| Move from lane 1 to lane 3
"Q"| Quit the game

5. Installation and Run Instructions

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal in VS Code.
5. Run the Python file using the following command:

python car_racing_game.py

If your Python file has a different name, replace "car_racing_game.py" with that filename.

---

6. How to Play

1. Start the program.
2. Check the player's lane and the randomly generated enemy lane.
3. Enter a movement command ("A", "D", "AA", "DD") or "Q" to quit.
4. Avoid the enemy and do not cross the road boundaries.
5. The game displays the score when it ends.

---

7. Testing Instructions

Run the program and check the following:

- "A" moves the car one lane to the left.
- "D" moves the car one lane to the right.
- "AA" moves the car from lane 3 to lane 1.
- "DD" moves the car from lane 1 to lane 3.
- The game ends if the car collides with an enemy.
- The game ends if the player attempts to cross a road boundary.
- "Q" quits the game.
- The final score is displayed when the game ends.
